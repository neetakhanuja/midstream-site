# Midstream

Concept website for Midstream, a four-week program that helps people in midlife and later life understand what a transition is changing in their lives.

Plain HTML, CSS and JavaScript. Open `index.html` to view locally. Served with GitHub Pages.

- `images/` holds the card images. Replace them with photos of the printed cards, keeping the same file names.
- Search `index.html` for `[CONTACT EMAIL]` to add a contact address.
